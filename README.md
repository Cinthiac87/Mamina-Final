# Mamina Deleites

Sitio web responsive de Mamina Deleites, dedicado a la presentación de cereales, granolas, frutos secos y productos saludables.

## Tecnologías utilizadas

- HTML5
- CSS3
- SCSS
- Bootstrap
- CSS Grid
- Flexbox
- AOS (Animate On Scroll)

## Características

El sitio cuenta con cinco páginas HTML, diseño responsive para dispositivos móviles, tablets y escritorio, navbar de Bootstrap, animaciones, optimización SEO y estilos desarrollados con SCSS.
